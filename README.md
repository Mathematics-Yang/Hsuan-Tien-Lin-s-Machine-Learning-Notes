# 林轩田机器学习笔记（含《机器学习基石》《机器学习技法》）

机器学习作为人工智能的核心分支，核心价值在于让计算机摆脱对预设程序的依赖，通过数据自主学习并优化——从海量信息中挖掘潜在模式与特征，最终构建出能对新数据进行精准预测和决策的模型。  

这种能力已深度渗透到各行各业：在电商领域，它依据用户行为数据推送心仪商品，同时提升商家转化率；在医疗场景，结合病历与影像资料辅助疾病早期诊断，为救治争取时间；在自动驾驶技术中，通过分析环境感知数据实现实时路况判断，保障行驶安全。


## 学习挑战与笔记价值
机器学习的知识体系庞大而复杂，涵盖抽象概念、严谨理论与多样算法。初学者常面临多重挑战：从基础定义、模型分类，到感知机、线性回归等入门算法的理解与实现，再到核函数、支持向量机、神经网络等进阶内容的探索，不仅需要概率论、线性代数、数理统计等数学基础支撑，还需掌握编程技能以实现理论落地。  

本笔记基于经典教材《Learning from Data》，深度融合台湾大学林轩田老师广受好评的“机器学习基石”与“机器学习技法”课程内容，系统梳理机器学习知识脉络：  
- 从基础概念切入，逐步解析“机器何时能学习”“为何能学习”等理论根基；  
- 延伸至“如何学习”“怎样学得更好”等实践层面，涵盖线性模型、非线性变换、正则化、核方法、集成学习等核心主题；  
- 理论上，清晰解读VC维、泛化误差等关键概念，夯实基础；  
- 实践中，详解感知机、逻辑回归、支持向量机等经典算法的实现思路、应用场景与案例分析，助力理论与实践结合。
